## Intent

2026 마이AI랩 「AI-이음 프로젝트」 중간보고용 기능 시연 영상. 사용자 요청 원문: "현재 구현된 화면을 위주로 영상을 나눠서 기능이 어떻게 동작되는지 발표영상을 만들어야한다. 발표자료2.pptx는 예전 문서이니 이를 참조로 현재 구현된 기능위주로 영상을 기능별로 나눠서 관리자모드, 활동자모드 등 너가 발표한다고 생각하고 보기좋게 영상을 만들어 주시오."

발표자가 화면을 짚어 가며 설명하는 톤. 실제 운영 화면(dolbomieum.kr) 캡처를 주인공으로, 한국어 내레이션과 자막으로 안내한다.

## Assets

- ../../doc/발표자료2.pptx — 예전 발표자료. 문제 정의·3대 기능·운영 원칙 문구의 출처(가상 연출도는 쓰지 않고 실제 화면으로 대체).
- assets/screens/ — 운영 사이트를 시험 계정(시험 현장 A·시험 관리자 A)으로 로그인해 캡처한 화면. 기록 작성 흐름은 STT·AI·저장 API 응답을 시연용 고정 응답으로 바꿔 캡처(운영 DB에 기록을 남기지 않음).

## Customizations

- 기능별 분할: 00 인트로 · 현장인력 01~03 · 관리자 04~06 · 07 마무리. 각 편을 따로 렌더링하고, 전체 이어 붙인 판도 만든다.
- 한국어 내레이션: edge-tts ko-KR-SunHiNeural (HeyGen/Gemini는 로그인·키가 필요해 제외).
- 자막: 내레이션 문장 단위.
