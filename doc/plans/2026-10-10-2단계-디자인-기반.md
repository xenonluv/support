# 2단계 디자인 기반 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 시안(`doc/design_ui.png`)의 색·글꼴·카드 스타일을 테마로 만들고, 공통 컴포넌트와 더미 데이터로 관리자 대시보드·알림 상세·현장 화면 틀을 렌더링한다.

**Architecture:**
- 색은 `globals.css`의 CSS 변수(shadcn 토큰 + 상태색 토큰)로만 정의하고, 화면은 Tailwind 클래스(`text-caution`, `bg-sidebar` 등)로 쓴다.
- 계산이 들어가는 로직(스파크라인 좌표, 대상자 표시 문구, 클립보드 복사)은 `src/lib/`에 순수 함수로 분리해 TDD로 만든다. 화면 컴포넌트는 그 결과를 그리기만 한다.
- 더미 데이터는 `src/lib/demo.ts` 한 파일에 모은다. 5단계(로그인·DB)와 7단계(이상징후)에서 실제 데이터로 바꾼다.

**Tech Stack:** Next.js 16.4 (App Router, Cache Components) · Tailwind CSS 4 · shadcn 4 (base-nova) · lucide-react · Pretendard 1.3.9 (OFL) · Vitest 5

**Spec:** `doc/단계개발.md` 5장 "2단계 — 디자인 기반"과 시안 `doc/design_ui.png`

## Global Constraints
- 사용자 결정(2026-10-10)
  - 글꼴은 **Pretendard**. 화면에 쓰인 글자 조각만 받는 dynamic subset 방식으로 쓴다.
  - 대상자 표시는 **식별번호 + 연령대 + 동**만 쓴다(예: `C-0012 · 70대` / `서구 화정1동`). 성명·별칭은 표시하지 않는다.
  - 현장 화면은 **틀까지**만 만든다: 오늘의 방문, 기록하기(녹음 버튼 모양만), 내 기록(빈 상태).
- 시안과 다르게 구현하는 부분 (spec)
  - "이음기록" 대신 **"돌봄이음"**
  - [전송하기] 대신 **[복사]**
  - [사례회의 소집]은 만들지 않는다
- 이상징후는 5종(약 미복용, 식사량 감소, 낙상, 정서적 위축, 방문 거부)만 더미 데이터에 쓴다. 시안 3번 "난방 미사용·관리비 체납"은 결정 전이라 쓰지 않는다.
- 상태색: 주의=빨강, 관찰=주황, 정상·해소=청록, 사이드바=남색, 주요 버튼=보라(인디고). 작은 글자(배지)는 흰 바탕 대비 4.5:1 이상이 되도록 진한 색조를 쓴다.
- 모든 AI 결과 화면 하단에 "AI는 판정하지 않고, 담당자에게 확인을 요청합니다"를 표시한다.
- 더미 데이터 화면에는 "미리보기" 안내 띠를 표시한다(3단계 배포 후 실제 데이터로 오해하지 않도록).
- 화면 컴포넌트(.tsx)는 단위 테스트 대신 **빌드와 스크린샷**으로 확인한다. 로직은 `src/lib/`로 분리해 TDD로 만든다.
- Next.js 16 규칙: 라우트 그룹 레이아웃은 `{ children }: { children: React.ReactNode }`로 받는다(`LayoutProps<"/..">`는 그룹 레이아웃에서 타입 오류). 동적 경로는 `generateStaticParams`가 1개 이상 값을 반환해야 하고, `dynamicParams`는 쓸 수 없다(Cache Components).
- 커밋은 사용자가 요청할 때만 한다. 결정이 필요하면 사용자에게 묻는다.
- 완료 확인: `npm run typecheck && npm run lint && npm test && npm run build` (모두 `web/`에서)

`web/src/lib/sparkline.ts`:
```ts
export type Bar = { x: number; y: number; width: number; height: number };

// 선 굵기만큼 위아래 여백을 둬 선이 잘리지 않게 한다
const PAD = 2;

/** 값 목록을 width×height 상자 안의 꺾은선 SVG path로 바꾼다. */
export function toLinePath(values: readonly number[], width: number, height: number): string {
  if (values.length === 0) return "";
  const ys = scaleY(values, height);
  if (values.length === 1) return `M0 ${ys[0]} L${width} ${ys[0]}`;
  const step = width / (values.length - 1);
  return ys.map((y, i) => `${i === 0 ? "M" : "L"}${round(i * step)} ${y}`).join(" ");
}

/** 값 목록을 막대 좌표로 바꾼다. 가장 큰 값이 상자 높이를 채운다. */
export function toBars(values: readonly number[], width: number, height: number, gap = 2): Bar[] {
  if (values.length === 0) return [];
  const max = Math.max(...values, 0);
  const barWidth = (width - gap * (values.length - 1)) / values.length;
  return values.map((v, i) => {
    const h = max === 0 ? 0 : round((Math.max(v, 0) / max) * height);
    return { x: round(i * (barWidth + gap)), y: round(height - h), width: round(barWidth), height: h };
  });
}

function scaleY(values: readonly number[], height: number): number[] {
  const min = Math.min(...values);
  const max = Math.max(...values);
  if (min === max) return values.map(() => round(height / 2));
  const usable = height - PAD * 2;
  return values.map((v) => round(PAD + (1 - (v - min) / (max - min)) * usable));
}

function round(n: number): number {
  return Math.round(n * 100) / 100;
}
```

type ClipboardLike = { writeText(text: string): Promise<void> };

/** 텍스트를 클립보드에 복사한다. 클립보드를 쓸 수 없거나 브라우저가 거부하면 false. */
export async function copyText(
  text: string,
  clipboard: ClipboardLike | null = defaultClipboard(),
): Promise<boolean> {
  if (!clipboard) return false;
  try {
    await clipboard.writeText(text);
    return true;
  } catch {
    return false;
  }
}

function defaultClipboard(): ClipboardLike | null {
  return typeof navigator !== "undefined" && navigator.clipboard ? navigator.clipboard : null;
}

export function CopyButton({ text, className }: { text: string; className?: string }) {
  const [state, setState] = useState<State>("idle");

import { useState } from "react";

/** 연계 알림 문안. [수정]으로 고친 뒤 [복사]해 기존 채널(문자·메신저)로 사람이 보낸다. */
export function AlertDraft({ initialText }: { initialText: string }) {

  const [editing, setEditing] = useState(false);

  return (
    <section aria-labelledby="draft-heading" className="rounded-xl bg-muted p-4">

      </h2>

        <textarea
          aria-label="연계 알림 문안 수정"
          value={text}
          onChange={(e) => setText(e.target.value)}
          rows={6}
          className="mt-3 w-full rounded-lg border bg-card p-3 text-sm leading-relaxed"
        />
      ) : (
        <p className="mt-3 rounded-lg border bg-card p-3 text-sm leading-relaxed whitespace-pre-wrap">{text}</p>
      )}
      <div className="mt-3 grid grid-cols-2 items-start gap-2">
        <Button variant="outline" size="lg" className="h-11 text-base" onClick={() => setEditing((v) => !v)}>
          {editing ? "수정 완료" : "수정"}
        </Button>
        <CopyButton text={text} />
      </div>
    </section>
  );
}
