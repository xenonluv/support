# 4단계 마이크 스모크 테스트 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 휴대폰 브라우저에서 마이크 권한·녹음·재생이 되는지 확인하는 `/mic-test` 페이지와, 6단계에서 다시 쓸 녹음 모듈(`src/lib/audio`)을 만든다.

**Architecture:**
- 판단 로직(녹음 형식 선택, 브라우저·인앱 판별, 외부 브라우저 열기 주소, 권한 안내 문구, 결과 요약)은 `src/lib/audio/`의 순수 함수로 만들고 TDD로 검증한다.
- 브라우저 API를 다루는 부분은 React 훅 두 개로 감싼다. `useRecorder`는 MediaRecorder·Wake Lock·2분 자동 종료를, `useSpeechPreview`는 Web Speech를 맡는다.
- 녹음은 브라우저 메모리(Blob URL)에서만 재생하고 서버로 보내지 않는다.
- 결과는 "결과 복사" 버튼으로 텍스트를 만들어 사용자가 붙여 넣는다. 구술 내용 자체는 넣지 않는다.
- 아이폰 홈 화면 앱(PWA) 테스트를 위해 manifest·아이콘·safe-area 설정을 넣는다.

**Tech Stack:** Next.js 16.4 · React 19.3 · MediaRecorder / getUserMedia / Web Speech / Screen Wake Lock API · Vitest 5

**Spec:** `doc/단계개발.md` 5장 "4단계 — 마이크 스모크 테스트", `doc/구현1.md` 9-1장

## Global Constraints
- 음성은 서버·스토리지·로그 어디에도 보내거나 저장하지 않는다 (CLAUDE.md 개인정보 규칙). 결과 복사 텍스트에도 구술 내용은 넣지 않고 글자 수만 넣는다.
- 녹음 형식은 `MediaRecorder.isTypeSupported()`로 고른다: `audio/webm;codecs=opus` → `audio/webm` → `audio/mp4` → `audio/ogg;codecs=opus` → 없으면 브라우저 기본값.
- 최대 녹음 길이는 2분이고, 넘으면 자동으로 종료한다.
- 인앱 브라우저는 UA로 판별한다: 카카오톡 `KAKAOTALK`, 인스타그램, 페이스북 `FBAN|FBAV`, 라인 `Line/`, 밴드 `BAND/`, 판별 불가 웹뷰(안드로이드 `; wv)`, iOS에서 `Safari` 토큰 없음).
  - 카카오톡은 `kakaotalk://web/openExternal?url=`로 외부 브라우저를 연다.
  - 그 밖의 안드로이드 인앱은 크롬 intent 주소로 연다.
  - iOS 인앱은 메뉴로 여는 방법을 안내한다.
- 권한이 거부되면 기기별 설정 방법을 보여 준다(구현1.md 9-1 구현 대응 2).
- React 린트 규칙(react-hooks v7: `set-state-in-effect`, `refs`, `purity`)을 지킨다.
  - 렌더 중에는 `Date.now()`나 ref를 읽지 않는다.
  - 브라우저 정보는 `useSyncExternalStore`로 읽는다.
- 커밋은 사용자가 요청할 때만 한다. 실기기 테스트는 배포 후 사용자가 한다.
- 완료 확인: `npm run typecheck && npm run lint && npm test && npm run build`

## Review Focus
- 녹음 중에 2분이 지나는 경우 → 자동으로 멈추고, 결과에 "2분 자동 종료"가 표시되어야 한다 (Task 3 Step 4, 가짜 마이크로 짧은 제한을 걸어 확인)
- 권한 거부 → 멈춘 버튼만 보여서는 안 되고 기기별 설정 안내가 떠야 한다 (Task 2 `permissionHelp` 테스트 + Task 3 화면)
- 녹음을 여러 번 반복 → 이전 Blob URL을 해제하고 마이크(빨간 점)도 꺼져야 한다 (Task 3 Step 4, 반복 녹음 후 트랙 상태 확인)
- 녹음을 마친 뒤 화면 꺼짐 방지가 계속 켜져 있으면 배터리를 쓴다 → 종료 시 해제해야 한다 (`useRecorder`의 release)
- 카카오톡 안에서 열기 → 외부 브라우저로 여는 버튼이 정확한 주소여야 한다 (Task 2 `externalOpenUrl` 테스트)
