# 1단계 프로젝트 뼈대 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `web/`에 Next.js 앱을 만들고, 검증 명령 3개(typecheck·lint·test)와 빌드가 통과하는 개발 기반과 프로젝트 규칙 문서(`CLAUDE.md`)를 갖춘다.

**Architecture:** 저장소 루트에는 문서(`doc/`)와 `CLAUDE.md`만 두고 앱은 `web/` 하위에 둔다. create-next-app 16.4의 기본 구성(App Router, Tailwind 4, Turbopack, Cache Components)을 그대로 쓰고, shadcn은 기본 프리셋(base-nova)으로 초기화한다. 이후 단계에서 쓸 폴더 골격만 만들고 기능 코드는 넣지 않는다.

**Tech Stack:** Next.js 16.4 · React 19.3 · TypeScript 5 (strict) · Tailwind CSS 4 · shadcn 4 (base-nova) · Vitest 5 · Prettier 3 · Node 24 LTS

**Spec:** `doc/단계개발.md` 5장 "1단계 — 프로젝트 뼈대" (근거: `doc/Mac구축.md` 3-1~3-4장)

## Global Constraints
- 앱 위치는 `web/`. npm 명령은 모두 `web/`에서 실행한다.
- `tsconfig.json`의 `"strict": true`를 유지한다.
- 스크립트는 `dev`, `build`, `lint`, `typecheck`, `test`를 둔다.
- Node 버전은 `engines.node`와 `web/.nvmrc` 두 곳에 고정한다. 현재 설치 버전은 v24.13.0이며 Node 24 LTS 기준이다.
- `.env.example`은 커밋하고 `.env.local`은 git에서 제외한다.
- `NEXT_PUBLIC_` 접두사는 Supabase URL·anon key에만 쓴다.
- 커밋은 사용자가 요청할 때만 하고 메시지는 한국어로 쓴다. 이 계획에는 커밋 단계가 없고 마지막에 사용자에게 묻는다.
- 결정이 필요한 사항은 추측하지 말고 사용자에게 묻는다.
